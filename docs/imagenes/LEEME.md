# Imágenes para la web de Fuelfy

Sube aquí las imágenes para la landing y la app (GitHub → esta carpeta → **Add file → Upload files**).

- **Formatos:** JPG o WebP para fotos, PNG o SVG para logotipos e iconos.
- **Tamaño:** mejor por debajo de 500 KB cada una; para fotos a pantalla completa, unos 2000 px de ancho bastan.
- **Nombres:** en minúsculas, sin espacios ni acentos (por ejemplo `camion-gasolinera.jpg`).
- **Ojo:** todo lo que hay en esta carpeta es público en fuelfy.app. Evita matrículas legibles, caras de personas
  sin su permiso y fotos con derechos de otros (bancos de imágenes sin licencia).
